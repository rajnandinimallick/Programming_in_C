# Programming in C

A comprehensive collection of C programming examples, exercises, and problem-solving implementations inspired by the book **"Programming in C"** by **Stephen G. Kochan**.

This repository is intended as a personal learning resource for practicing the fundamentals and advanced concepts of the C programming language. The examples are adapted from the book and, where appropriate, expanded with additional explanations, comments, and alternative solutions to reinforce understanding.

## Objectives

- Practice core C programming concepts through hands-on coding.
- Solve programming exercises from each chapter.
- Build a well-organized reference for common C programming techniques.
- Improve problem-solving skills by implementing multiple approaches to selected problems.
- Document solutions with clear comments for future reference.

## Topics Covered

- Introduction to C Programming
- Variables, Data Types, and Operators
- Program Control (if, switch, loops)
- Functions and Recursion
- Arrays and Strings
- Pointers
- Structures and Unions
- Enumerations
- Bitwise Operators
- File Handling
- Dynamic Memory Allocation
- Preprocessor Directives
- Advanced C Concepts
- Practice Problems and Chapter Exercises
